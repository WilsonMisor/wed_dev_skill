# Infrastructure Backup

Coordinate database, file, configuration, and platform recovery needs.

## Plan

1. What is backed up.
2. Frequency and retention.
3. Encryption and access.
4. Independent copy or provider separation where required.
5. Configuration needed to rebuild infrastructure.
6. Recovery Point Objective.
7. Recovery Time Objective.
8. Restore procedure.
9. Restore testing.
10. Integrity verification.

Infrastructure as code does not replace data backup, and data backup does not replace reproducible infrastructure configuration.
