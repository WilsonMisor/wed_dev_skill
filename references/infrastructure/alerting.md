# Alerting

Alerts are for conditions requiring timely human or automated response.

## Each alert defines

1. Condition.
2. Severity.
3. User impact.
4. Threshold and duration.
5. Notification destination.
6. Owner.
7. Runbook.
8. Escalation.
9. Suppression or maintenance behaviour.
10. Resolution criteria.

Separate informational dashboards from paging signals. Repeated false alarms must be corrected rather than normalized.
