# Traceability

Traceability prevents implementation from becoming disconnected from approved intent.

## Required chain

Map, as applicable:

1. Discovery evidence to PRD requirement.
2. PRD requirement to SRS requirement.
3. SRS requirement to SRD requirement.
4. Requirement to architecture decision and design evidence.
5. Requirement to data, API, security, and privacy controls.
6. Requirement to AI task packet.
7. Task packet to code or configuration change.
8. Requirement to automated and manual tests.
9. Defect to regression test.
10. Release to included requirement IDs and evidence.

Use stable IDs. Never silently renumber identifiers that have already been referenced by downstream artifacts.
