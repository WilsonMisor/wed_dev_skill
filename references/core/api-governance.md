# API Governance

Apply when components communicate through a programmatic contract.

## Governing principles

1. Contract first for shared business operations.
2. Stable naming and domain semantics.
3. Explicit authentication and authorization.
4. Input validation and output contracts.
5. Predictable error model.
6. Pagination, filtering, sorting, and limits where collections are exposed.
7. Idempotency for retryable state changing operations where duplicate effects are dangerous.
8. Versioning and compatibility plan.
9. Rate limiting and abuse controls where exposed.
10. Observability and audit events for material operations.
11. Contract tests between providers and consumers.
12. Documentation sufficient for independent consumers.

Use the detailed API profile for implementation rules.
