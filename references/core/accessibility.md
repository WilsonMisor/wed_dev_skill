# Accessibility Governance

Accessibility is a product requirement for user facing interfaces and documents when applicable.

## Cover

1. Keyboard operation.
2. Focus visibility and order.
3. Semantic structure and accessible names.
4. Form labels, instructions, validation, and errors.
5. Colour independent meaning and sufficient contrast.
6. Text scaling and responsive reflow.
7. Touch target usability.
8. Screen reader compatibility.
9. Motion and animation preferences.
10. Captions, transcripts, and alternatives for media where needed.
11. Loading, empty, success, warning, and error state accessibility.
12. Automated and manual accessibility verification.

Record target standard and approved exceptions. Automated scans do not replace manual interaction testing.
