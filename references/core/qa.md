# Quality Assurance

QA verifies the integrated product against requirements and realistic use, not only isolated code correctness.

## QA scope

1. Critical user journeys.
2. Role and permission variants.
3. Data validation and error recovery.
4. Empty, loading, offline, slow, timeout, retry, and failure states where applicable.
5. Responsive and device behaviour.
6. Browser compatibility where web is active.
7. Accessibility.
8. Security sensitive workflows.
9. Integrations and webhooks.
10. Upgrade, migration, and regression risks.
11. Installation, configuration, and environment assumptions.

Produce evidence with environment, build or commit, test case, expected result, actual result, defect severity, reproduction information, and verification result.
