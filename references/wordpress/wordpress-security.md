# WordPress Security Profile

Read `references/wordpress-cybersecurity-build-workflow.md` for the detailed authoritative controls.

## Profile checks

1. Core, theme, and plugin update strategy.
2. Least privilege roles and capabilities.
3. Authentication and admin protection.
4. Nonces for applicable state changing actions.
5. Input validation and output escaping.
6. Prepared database queries.
7. REST and AJAX authorization.
8. Upload security.
9. Secrets and environment configuration.
10. Backups and restore testing.
11. Rate limiting, WAF, network, and hosting controls where applicable.
12. Logging and monitoring.

Critical or high security findings remain launch blockers unless formally accepted by the accountable human owner.
