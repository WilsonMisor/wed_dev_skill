# WordPress QA

Combine the preserved WordPress visual completeness framework with core and browser QA.

## Test

1. All launch scope templates, not only the home page.
2. CPT singles, archives, taxonomies, search, 404, empty states, forms, success states, and error states.
3. Admin CPT data entry and media workflows.
4. Roles and capabilities.
5. Forms, email delivery, integrations, and spam controls.
6. Responsive layouts and browser behaviour.
7. Accessibility.
8. SEO rendered output.
9. Security sensitive actions.
10. Caching while logged in and logged out where relevant.
11. Backup, migration, and restore paths when in scope.

Use realistic content to detect layout and content resilience failures.
