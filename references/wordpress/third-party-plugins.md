# Third Party Plugin Integration

Use third party plugins only after fit, maintenance, security, licensing, compatibility, and operational impact are evaluated.

## Review

1. Required capability and alternatives.
2. Active maintenance and supported WordPress and PHP versions.
3. Security history and update process.
4. Data stored and external services contacted.
5. Performance impact.
6. Accessibility and frontend output.
7. Admin permissions.
8. Backup and migration behaviour.
9. Vendor lock in and replacement plan for critical functions.
10. Configuration required across environments.

Pin important configuration in documentation and test integrations after plugin updates.
