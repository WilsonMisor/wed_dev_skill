# WordPress Media Management

Use the WordPress media library or an approved managed media flow when site owners need to update images, documents, or other media.

## Requirements

1. Define allowed file types, size expectations, and security restrictions.
2. Use responsive WordPress image markup and generated sizes where appropriate.
3. Prefer modern image formats when operationally supported.
4. Keep intrinsic dimensions to reduce layout shift.
5. Lazy load non critical images and prioritise the actual LCP image when appropriate.
6. Define alternative text and editorial guidance.
7. Protect uploads and prevent executable or unsafe file handling.
8. Define replacement, deletion, orphan, backup, and migration behaviour.
9. Provide CMS fields for content managed media rather than hard coding assets that owners must change.
