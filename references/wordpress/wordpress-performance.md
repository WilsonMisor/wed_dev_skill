# WordPress Performance

Measure the rendered site and optimise verified bottlenecks.

## Cover

1. Theme and plugin asset loading.
2. Database query count and expensive queries.
3. Object, page, browser, and CDN caching where appropriate.
4. Image sizing and modern formats.
5. Font loading.
6. Critical CSS and render blocking resources where relevant.
7. Third party scripts.
8. Cron and background work.
9. Hosting PHP and database configuration within available access.
10. Core Web Vitals on representative pages.

Do not add complex optimisation plugins or caching layers without understanding their invalidation and operational impact.
