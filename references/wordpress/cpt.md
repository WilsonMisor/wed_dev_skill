# Custom Post Types

CPTs must model content and workflows intentionally.

## Define

1. Purpose and ownership.
2. Labels, capabilities, visibility, archives, rewrite rules, REST exposure, and taxonomy relationships.
3. Required metadata and media.
4. Admin list columns, filters, sorting, and validation where useful.
5. Frontend templates and states.
6. Search and SEO behaviour.
7. Import, export, migration, and deletion behaviour.

For project CPTs that require structured data entry, do not default users into Gutenberg. Provide purpose built custom metadata or metabox interfaces with WordPress media selection where required, unless explicit approval authorises another editor experience.
