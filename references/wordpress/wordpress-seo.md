# WordPress SEO Profile

Read the existing SEO workflow and applicability matrix for detailed requirements.

## WordPress specific coverage

1. Page, post, CPT, taxonomy, archive, author, search, pagination, and attachment indexation decisions.
2. Canonicals and duplicate content.
3. XML sitemap behaviour.
4. Metadata ownership between theme, core, and SEO plugin.
5. Structured data based on truthful content.
6. Internal links and breadcrumbs where applicable.
7. Redirects after URL changes.
8. Image and media SEO.
9. Robots and noindex controls.
10. Full staging crawl and remediation before launch.

Preserve the existing target of strong audit performance and documented exceptions without claiming ranking guarantees.
