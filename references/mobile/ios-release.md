# iOS Release

## Prepare

1. Bundle identifier and signing team.
2. Version and build numbering.
3. Supported iOS versions and devices.
4. Entitlements and capabilities.
5. Privacy usage descriptions.
6. Release configuration.
7. App Store Connect metadata and privacy declarations as applicable.
8. TestFlight validation.
9. Review account or demo access if required.
10. Crash monitoring.
11. Phased release and halt criteria.
12. Server compatibility with older supported versions.

Test the archive or distribution build, not only a development build.
