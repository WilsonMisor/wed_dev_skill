# Mobile Analytics

Analytics should answer approved product questions, not collect data by default.

## Define

1. Event catalogue.
2. Event purpose.
3. Required properties.
4. User and tenant identity rules.
5. Consent and privacy requirements.
6. Offline buffering and retry.
7. Duplicate handling.
8. Versioning when event meaning changes.
9. Development and test filtering.
10. Data retention and access.

Do not put secrets, tokens, full sensitive content, or unnecessary personal data into analytics events.
