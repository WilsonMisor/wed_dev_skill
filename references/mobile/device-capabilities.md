# Device Capabilities

Treat camera, microphone, location, biometrics, contacts, files, sensors, Bluetooth, NFC, and similar capabilities as optional platform dependencies unless the product fundamentally requires them.

## For each capability define

1. Supported use case.
2. Permission requirements.
3. Hardware availability check.
4. Platform differences.
5. Failure and fallback behaviour.
6. Privacy and security controls.
7. Data lifecycle.
8. Battery and performance impact.
9. Emulator limitations.
10. Real device test coverage.
