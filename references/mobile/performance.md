# Mobile Performance

Measure performance on representative physical devices, including lower capability devices within the support target.

## Evaluate

1. Startup and time to usable state.
2. Frame rendering and jank.
3. Memory usage and leaks.
4. Network payloads and latency.
5. Image decoding and caching.
6. Local database queries.
7. Background work.
8. Battery impact.
9. Application size.
10. Release build performance.

Optimise measured bottlenecks. Debug mode measurements are not valid evidence for release performance.
