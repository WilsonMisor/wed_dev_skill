# Mobile Delivery Lifecycle

Mobile is a distinct delivery surface with device, connectivity, signing, distribution, and installed version concerns.

## Lifecycle

1. Product and device requirements.
2. Mobile architecture.
3. UX and responsive or adaptive design.
4. API and canonical domain contracts.
5. Authentication and secure storage.
6. Local persistence.
7. Offline and synchronization behaviour.
8. Permissions and device capabilities.
9. Notifications, links, and background behaviour.
10. Automated and device testing.
11. Signing and build variants.
12. Store testing and compliance.
13. Staged production release.
14. Crash and operational monitoring.
15. Upgrade, compatibility, deprecation, and incident response.

Do not assume installed clients upgrade immediately. Server changes must account for supported older app versions.
