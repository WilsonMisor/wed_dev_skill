# Android Release

## Prepare

1. Package identifier and signing identity.
2. Version code and version name policy.
3. Supported Android versions.
4. Release build configuration and environment.
5. Permissions and manifest review.
6. App bundle or required artifact.
7. Store listing, privacy, data safety, and content declarations as applicable.
8. Internal or closed testing before production.
9. Crash and performance monitoring.
10. Staged rollout and halt criteria.
11. Server compatibility with older supported versions.
12. Upgrade and emergency mitigation plan.

Verify the exact signed release artifact that will be distributed.
