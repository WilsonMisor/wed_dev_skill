# Mobile Accessibility

Apply core accessibility with platform specific mobile interaction.

## Verify

1. Screen reader labels and traversal.
2. Dynamic text scaling.
3. Contrast and colour independent meaning.
4. Touch target size and spacing.
5. Focus and keyboard support where relevant.
6. Orientation and layout adaptation.
7. Reduced motion.
8. Form errors and status announcements.
9. Accessible custom controls.
10. Platform semantics and actions.

Test representative screens with Android and iOS accessibility tooling when both platforms are supported.
