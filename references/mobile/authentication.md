# Mobile Authentication

Define mobile identity and session behaviour across app restarts, device compromise assumptions, and token expiry.

## Cover

1. Login and identity provider flow.
2. Browser based OAuth or platform flow when used.
3. Access and refresh token lifecycle.
4. Secure storage.
5. Logout and revocation.
6. Expired or revoked sessions.
7. Device change and account recovery.
8. Biometric convenience versus actual server authentication.
9. Suspended or deleted account behaviour.
10. Audit and error handling.

Never treat possession of local application state as sufficient authorization for a server resource.
