# Mobile Navigation

Navigation must support expected device behaviour and deep entry points.

## Define

1. Route structure.
2. Authentication gates.
3. Role and entitlement gates.
4. Deep links and universal or app links.
5. Back behaviour.
6. Tab or nested navigation if used.
7. Restoration after process death when required.
8. Invalid or expired route parameters.
9. Notification initiated navigation.
10. Analytics and test coverage.

Authorization remains server side. Navigation guards improve UX but are not a security boundary.
