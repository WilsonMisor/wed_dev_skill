# Data Backups

Define backups by business recovery requirements.

## Record

1. Data and systems included.
2. Frequency.
3. Retention.
4. Encryption.
5. Access.
6. Offsite or independent copy requirement.
7. Recovery Point Objective.
8. Recovery Time Objective.
9. Restore procedure.
10. Restore verification schedule.
11. Data consistency across database and object storage where both matter.

A provider claiming backups exist is not sufficient evidence that your application can be restored within required objectives.
