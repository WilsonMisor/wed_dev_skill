# Web SEO

Apply only to content intended for search discovery.

## Cover

1. Crawlable information architecture.
2. Stable descriptive URLs.
3. Unique titles and meaningful descriptions where applicable.
4. Canonicals.
5. Robots and noindex rules.
6. XML sitemaps when appropriate.
7. Internal linking.
8. Structured data only when supported by visible truthful content.
9. Rendered content availability to search engines.
10. Image metadata and performance.
11. Redirect management.
12. Error and not found behaviour.
13. Core Web Vitals and performance related discoverability.
14. Crawl validation before release.

Do not promise rankings. Do not generate fake reviews, locations, people, or unsupported schema claims.
