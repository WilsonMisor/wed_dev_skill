# Web Architecture

Use for browser delivered products, including public sites, authenticated applications, portals, and browser clients for SaaS.

## Define

1. Rendering model, including server rendered, static, client rendered, hybrid, or progressively enhanced behaviour.
2. Route and navigation architecture.
3. Frontend and backend boundaries.
4. Authentication and session boundaries.
5. Data fetching, caching, invalidation, and error handling.
6. Asset and media delivery.
7. Browser storage and sensitive data restrictions.
8. Accessibility and responsive behaviour.
9. Performance budgets.
10. SEO requirements when indexable content exists.
11. Observability and browser error reporting.
12. Deployment and rollback behaviour.

Document tradeoffs when framework choices materially affect security, accessibility, performance, hosting, or maintainability.
