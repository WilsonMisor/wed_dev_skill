# Responsive Design

Responsive behaviour must be designed, not left to accidental wrapping.

## Requirements

1. Define content priority and layout changes across narrow, medium, and wide viewports.
2. Ensure navigation remains usable without hidden critical actions.
3. Prevent horizontal overflow except intentionally scrollable regions.
4. Preserve readable line length and scalable text.
5. Use touch appropriate controls and spacing.
6. Recompose dense tables, filters, dashboards, and multi column forms deliberately.
7. Test orientation and viewport changes where relevant.
8. Ensure images and media use appropriate responsive sizing.
9. Avoid device specific assumptions unless the product explicitly targets them.
10. Verify responsive states with realistic content lengths.
