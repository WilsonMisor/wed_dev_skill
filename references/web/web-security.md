# Web Security

Apply the core security process to browser specific threats.

## Cover

1. Cross site scripting prevention through contextual output handling and safe framework primitives.
2. Cross site request forgery protection for state changing requests when relevant.
3. Clickjacking and framing policy.
4. Content Security Policy where feasible.
5. Secure transport and cookie settings.
6. Open redirect prevention.
7. CORS based on explicit trusted origins rather than permissive defaults.
8. File upload validation and storage isolation.
9. Server side authorization.
10. Rate limiting and abuse controls.
11. Dependency and supply chain hygiene.
12. Security headers appropriate to the architecture.

Security controls must be tested through negative paths and not inferred from framework defaults.
