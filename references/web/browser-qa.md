# Browser QA

Test rendered behaviour in real browsers for launch scope web work.

## Cover

1. Critical journeys.
2. Navigation, refresh, deep links, and back or forward behaviour.
3. Forms, validation, submission, duplicate submission, and errors.
4. Authentication and session expiry.
5. Responsive layouts across representative viewport sizes.
6. Keyboard and screen reader relevant behaviour.
7. Loading, slow network, offline, timeout, and failed request states where applicable.
8. Browser storage and cache behaviour.
9. Downloads, uploads, media, and printing where applicable.
10. Console errors, failed network requests, and unexpected redirects.

Use gstack QA or equivalent real browser tooling when available. Record browser versions or engines actually tested and do not claim untested compatibility.
