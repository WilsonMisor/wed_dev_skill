# Web Performance

Set budgets before optimisation becomes subjective.

## Evaluate

1. Largest Contentful Paint and critical rendering path.
2. Interaction responsiveness.
3. Layout stability.
4. JavaScript and CSS size.
5. Image and font delivery.
6. Server response and API latency.
7. Caching.
8. Third party scripts.
9. Long tasks and hydration cost where applicable.
10. Mobile network and lower power device behaviour.

Use real measurements from representative builds. Optimise the largest verified bottleneck first. Avoid trading accessibility, correctness, or security for small synthetic score improvements.
