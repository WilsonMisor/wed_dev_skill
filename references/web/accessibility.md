# Web Accessibility

Apply the core accessibility requirements with browser specific implementation checks.

## Web checks

1. Semantic HTML before ARIA replacement.
2. Logical heading structure and landmarks.
3. Keyboard reachable interactive elements.
4. Visible focus and logical focus movement.
5. Labels and accessible names for controls.
6. Correct live region use for asynchronous status where needed.
7. Accessible modal, menu, disclosure, tab, and dialog behaviour.
8. Contrast and colour independent meaning.
9. Zoom and text reflow.
10. Reduced motion support where animation is significant.
11. Accessible validation and error summaries.
12. Manual screen reader and keyboard verification for critical flows.

Do not use automated accessibility scores as the sole evidence of conformance.
