# Feature Flags

Feature flags are temporary or controlled release mechanisms, not permanent undocumented authorization systems.

## Define

1. Flag owner.
2. Purpose.
3. Default state.
4. Targeting scope.
5. Environment behaviour.
6. Interaction with plans and permissions.
7. Rollout and rollback criteria.
8. Telemetry.
9. Removal date or condition.
10. Failure behaviour if the flag service is unavailable.

Do not use a feature flag to bypass required authorization or security controls.
